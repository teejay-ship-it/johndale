# Euroform Estimating SOP – Office Engineer

A single-page website version of the **Standard Operating Procedure: Manual Process for Estimating Euroform Materials**, written for newly hired office engineers on concrete construction projects.

## What's inside

- Purpose, scope, and required documents and tools
- The 8-step manual estimation process, with an interactive verification checklist
- Links to the Euroform catalog, estimation worksheet, and rental/sale quotation templates
- Responsibilities, common mistakes, 5-day training workflow, and final output requirements
- Light and dark themes, mobile-friendly layout

## Files

| File | Purpose |

## Publish on GitHub Pages

1. Create a new repository on GitHub (for example `euroform-sop`).
2. Upload `index.html`, `.nojekyll`, and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Choose the **main** branch and the **/ (root)** folder, then click **Save**.
6. After a minute or two, the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Run locally

Open `index.html` in any web browser. No build step or installation is needed. An internet connection is only used to load the Barlow fonts from Google Fonts; the page falls back to system fonts without it.

## Editing

All content is in `index.html`. Search for the section `id` (for example `id="process"`) to find and edit text. The OneDrive and catalog links are in the Step 2 and Sample worksheet sections.
